# Diario de IA Educativa · Diari d'IA Educativa

Lo que el profesorado prueba y debate en tres comunidades abiertas de Telegram, [ChatGPT-IA-edu](https://t.me/ChatGPTedu),
[Vibe Coding Educativo](https://t.me/vceduca) y [EduMedia-IAG](https://t.me/EduMediaIAG).
Sale cada mañana a las 7:00, en castellano y, como *Diari d'IA Educativa*, en catalán. Su viñeta
diaria la protagonizan Tiza y Algoritmo.

- Castellano: https://diarioiaeducativa.github.io/
- Català: https://diarioiaeducativa.github.io/ca/
- RSS: [castellano](https://diarioiaeducativa.github.io/feed.xml) · [català](https://diarioiaeducativa.github.io/ca/feed.xml)

## Cómo se hace

Cada noche, una IA lee las conversaciones del día, elige lo que puede interesar fuera de los
grupos y lo redacta. Cada dato se comprueba en su fuente original, enlazada al final de cada
pieza, y otra IA repasa las piezas antes de publicarlas. La edición catalana es una traducción
automática con IA, sin revisión profesional. La idea del diario es de Raül Torres.

Este repositorio guarda el sitio ya generado; se publica con GitHub Pages. El código que lo genera
y los encargos de los agentes están en [diarioiaeducativa/periodico](https://github.com/diarioiaeducativa/periodico).
